## The UI kit folder

`docs/ui-kit/` mirrors the kit page's `project/` folder exactly, so it can be republished as-is:

| Path | What |
| --- | --- |
| `README.md` | Brand guide: principles, voice, colour, type, shape, motion, icons, accessibility |
| `tokens.json` | Every token with its Dark (default) and Light value and a usage note |
| `Screens.md`, `Navigation.md`, `Review-checklist.md` | Screen specs, current and proposed navigation, UI review checklist and open issues |
| `components/<Name>/README.md` | Guideline per component (20) |
| `components/<Name>/preview.html` | The page's preview of each component; needs `tokens.css` (generated by the page from `tokens.json`) and `components/bundle.css` |
| `components/Cover/preview.html` | The kit's cover |
| `components/bundle.css` | Plain-CSS port of the app's utilities in `src/app/globals.css` |
| `design-system.json` | The page's index (title, asset records) |
| `assets/Logos/` | FA mark, app icons, share card (same files as `public/`) |
| `fonts/` | Yekan Bakh (same file as `src/fonts/`) |

## Viewing them from this branch

The `dev-ui` preview site serves the live versions:
- Style guide rendered with the real components: `/farsi-pen/dev-ui/design/`
- System design: `/farsi-pen/dev-ui/present/system-design.html`

Source of truth stays in code (`src/app/globals.css`, `src/components/ui.tsx`). When a token or component changes, update `docs/ui-kit/` in the same pull request.
