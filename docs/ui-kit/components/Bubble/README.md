# Bubble

A small speech bubble with a pointer, used to call out the next step.

## When to use
"START" or "CONTINUE" above the current lesson node, bobbing gently; hints next to a hero illustration on the landing page.

## The screen provides
One or two words. Position it with a wrapper element; the bubble itself stays `position: relative` for its pointer.

Source: `Bubble` in `src/components/ui.tsx`.
